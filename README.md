# Quem Decide?

Assistente de informação cívica para compreender competências,
decisões e processos das instituições públicas brasileiras.

## Problema

Decisões públicas brasileiras frequentemente envolvem diferentes
entes federativos, Poderes e instituições.

Para o cidadão, nem sempre é simples identificar:

- quem possui competência para determinada decisão;
- quem efetivamente tomou uma decisão;
- quais instituições participaram do processo;
- em que etapa uma proposta ou mudança se encontra;
- quem possui competência para executar a próxima etapa.

O Quem Decide busca tornar essas relações institucionais mais
compreensíveis utilizando dados públicos, documentos oficiais e IA.

## Objetivo

Permitir perguntas em linguagem natural como:

- "Quem é responsável pela segurança pública?"
- "O presidente pode reduzir o ICMS?"
- "Quem decide o preço da passagem de ônibus?"
- "Essa decisão do TSE já é uma lei?"
- "O que falta para essa proposta entrar em vigor?"
- "Quem pode tomar a próxima decisão?"

e produzir respostas explicáveis e acompanhadas das respectivas
fontes oficiais.

## Princípios

- Neutralidade político-partidária
- Rastreabilidade das fontes
- Separação entre fato e interpretação
- Transparência sobre incertezas
- Priorização de fontes oficiais
- Não atribuição automática de culpa política

## O que o sistema não pretende fazer

O Quem Decide não determina quem é politicamente "culpado" por um
problema.

O sistema distingue:

1. competência institucional;
2. decisão documentada;
3. participação no processo;
4. capacidade institucional de ação;
5. interpretação política.

As quatro primeiras podem ser sustentadas por evidências documentais.
A quinta deve ser explicitamente identificada como interpretação e
não será apresentada como fato pelo sistema.
